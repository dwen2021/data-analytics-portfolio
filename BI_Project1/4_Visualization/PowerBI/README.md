## 📘 Overview  
Interactive Power BI dashboard analyzing U.S. insurance claim patterns, policy volume, and subscription length.  
Data cleaned with Python ETL, stored in Azure SQL, and visualized with KPI cards + heatmap + filters.  

---

## 📈 Key Visuals  
- **KPI Cards:** Total Policies · Claim Rate · Avg Subscription Length  
- **Heatmap:** Claim Rate by State (filterable by Segment / Region Tier / Age Group)  
- **Pie & Bar Charts:** Region Tier and Segment Analysis
