## 📘 Overview  
Interactive Tableau dashboard analyzing **claim rate**, **subscription duration**, and **regional policy distribution**.  
Data pipeline was prepared using Python and Azure SQL, then visualized through Tableau Desktop for advanced storytelling.  

---

## 📈 Key Visuals  
- **Claim Rate by Vehicle Safety Rating (NCAP)**  
- **Subscription Length by Segment & Safety Rating**  
- **Policy Distribution by Region Tier**  
- **Claim Rate by Customer Age Group**  
- **KPI Summary:** Total Policies, Claims, and Average Subscription
